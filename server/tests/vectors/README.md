# Golden vectors

Cross-language interop fixtures for the phase-1 spike (ADR-0018,
`tasks/rust-backend-spike.md` step 1). Committed regression guards.

- **Go-emitted** — tokens, an auth-proof (`pubkey`, `payload`, `signature`,
  `jcs_canonical` hex), and a CBOR archive blob (hex) + decoded values.
  Produced by a fixed-seed emitter in `server/` (no `time.Now()` in committed
  output). Asserts Rust reproduces/verifies the Go formats.
- **`ts-vectors.json`** — `canonicalize()` output (hex) for the same battery,
  checking JCS canonical bytes against the *production* signer too.
  Generated by `web/src/lib/jcs-interop-vectors.gen.test.ts` (`GEN_VECTORS=1`),
  which reads the inputs from `go-vectors.json` so the battery is single-sourced.

## Regeneration discipline (do not skip)

These vectors are an **independent oracle**: the Rust spike asserts `serde_jcs`/
`ciborium` match *them*. Regenerate ONLY from the Go and TS emitters above —
**never** from this crate (`server`). Producing the "expected" values from the
same `serde_jcs`/`ciborium` under test turns the conformance check into a circular
self-snapshot that would silently bless divergence (e.g. the `>2^53` integer case
in ADR-0018 Findings). If `jcs_battery_matches_go` goes red, the fix is to
understand the divergence — not to regenerate it away.
