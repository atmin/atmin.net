# Rust backend — interop spike (ADR-0018, phase 1)

The de-risking first artifact of the Rust backend experiment: prove the Rust
crates reproduce and verify the Go server's three wire formats against golden
vectors generated by the existing Go + TS code. If they don't — especially the
JCS canonicalization — that's a finding that reshapes the protocol/spec _before_
any handler work. Framework-independent (no Rocket surface yet).

**Decision:** [ADR-0018](../docs/decisions/adr-0018-rust-backend-experiment.md) — Draft, branch `rust-port-experiment`.

**Specs / sources of truth:**

- Token + auth-proof + JCS: [server/auth.go](../server/auth.go); spec [mvp-v0.1.md](../docs/specs/mvp-v0.1.md) (token format), [ADR-0012](../docs/decisions/adr-0012-backup-secret-rotation.md) (`key_version` in token & proof).
- Client JCS oracle: [web/src/lib/crypto.ts](../web/src/lib/crypto.ts) (`canonicalizeForSign`, `signAuthProofV2`) — uses the `canonicalize` npm pkg.
- Existing cross-language JCS fixture to mirror: `web/e2e/fixtures/jcs-rotation-vector.*`.
- CBOR archive encode/decode: [handlers.go:928-949](../server/handlers.go#L928) (`cbor.Marshal`/`Unmarshal` of `[]any`, dedup by `msg_id`).
- Go proof-construction reference: [signAuthProofKV](../server/handlers_test.go#L107).

## Spec (what the spike must prove)

Three wire formats must be byte-/semantically interoperable with the running system:

1. **Token** — `base64url(uid "." did "." kv "." base64url(HMAC-SHA256(secret, uid"."did"."kv)))`, unpadded base64url. Rust must produce byte-identical tokens for the same `(secret, uid, did, kv)` **and** parse + verify Go-produced tokens (4-segment only; reject 3-segment legacy).
2. **Auth proof** — Ed25519 over the **JCS-canonical (RFC 8785)** bytes of `{user_id, device_id, timestamp, key_version}`. Rust must (a) canonicalize byte-identically to _both_ Go (`gowebpki/jcs`) and TS (`canonicalize`), and (b) verify proofs signed by each.
3. **CBOR archive** — array of envelope objects (`fxamacker/cbor`). Rust (`ciborium`) must decode a Go-marshaled archive to correct values, and a Go-decode of a Rust-marshaled archive must match (semantic equality; byte-identity is a stretch finding).

**Exit:** all three green against golden vectors from Go _and_ TS. The JCS battery
(point 2a) is the load-bearing assertion — verify-only could pass for the wrong
reasons, so compare canonical bytes directly.
